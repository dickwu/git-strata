# git-strata 0.3.3 — groundwork for seamless upgrades

This release prepares the CLI and daemon for upgrading without a stop. It adds the `Busy upgrading` wire contract, request parking in the daemon during a handover, and `publish --dry-run`. **Upgrade the CLI and the daemon together**, as with 0.3.2.

## No store migration

The store schema stays at v7 and `DOWNGRADE_FLOOR` stays 0.3.0. No config edits are required.

## Wire compatibility floor

The CLI and daemon now check a 0.3.0 floor in both directions (`MIN_CLIENT` and `MIN_DAEMON`). A daemon whose status reply carries no release `version` (v0.2.0 sends none) is below the floor, and the CLI sends nothing more to it. See [upgrade-wire.md](../upgrade-wire.md).

## `Busy upgrading`

A daemon in a handover refuses work with `Busy upgrading` and `detail.retry_safe: true`. The CLI sends such a refusal again within the same retry budget as its capability probe (`--timeout SECS`, else `GIT_STRATA_TIMEOUT`). `config reload`, `mark` and `config relax` check their feature and send on that same call. The capability probe and any legacy parameter or envelope resend share that budget. A multi-repo checkpoint keeps its earlier results.

## Request parking

During a handover the daemon parks writes and the read-class requests that can write (`publish_plan`, cross-base `diff`, cold `grep` and `files`), up to 64 connections or 32 MiB; overflow returns a retry-safe `Busy upgrading`. An aborted handover replays them in order; a terminal stop answers each untouched request by ID with a retry-safe refusal. A shipped 0.3.x hook can miss a checkpoint on overflow. `git-strata daemon status` shows the target PID, parked count and outstanding work on daemons with `daemon.handover`. See [dispatcher-parking.md](../dispatcher-parking.md).

## `publish --dry-run`

`git-strata publish --dry-run` takes the normal workspace checkpoint of each selected repo and returns the publish plan without publishing.

## Dependencies

Cargo and bun dependencies are refreshed within Rust 1.100 (blake3 1.8.8, cc 1.12.0, plist 1.10.5, postcss 8.5.34 and other patch updates). The Turso engine stays pinned at `=0.9.0-pre.5`, with its internal crates held at pre.5.

## Validation

This release was built and tested by GitHub Actions (CI, wire compatibility and the release workflow) rather than on a local machine.
