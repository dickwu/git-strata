# git-strata 0.2.2 — Rust 1.90 and dependency upgrades

## No store migration

The store schema stays at v7 and no migration runs on the first 0.2.2 daemon
start. 0.2.1 and 0.2.2 open each other's stores, so there is no backup to make
for the schema and no downgrade procedure beyond reinstalling 0.2.1. As always,
upgrade the CLI, daemon and hook callers together and restart the existing
LaunchAgent with `launchctl kickstart -k gui/$(id -u)/com.gwd.git-stratad`;
never start a second daemon with `brew services`. No config edits are required.

## Keep config.toml on TOML 1.0 syntax

- 0.2.2 parses `config.toml` with toml 1.2, which follows the TOML 1.1
  specification and accepts syntax that only TOML 1.1 has, for example an
  inline table spread over several lines with a trailing comma.
- 0.2.1 and earlier binaries reject such a file as a syntax error
  (`rule: "toml"`), in both the CLI and the daemon.
- Write `config.toml` in TOML 1.0 syntax until every binary that reads it,
  including hook callers and the desktop app's bundled copies, is on 0.2.2.

## Store engine: turso 0.9.0-pre.5

- The embedded store engine moves from turso 0.9.0-pre.1 to 0.9.0-pre.5. A v7
  store written by 0.2.1 (pre.1) opens unchanged; a test now opens such a store
  on every build.
- Store behaviour, reply fields and error codes are unchanged.

## Building from source needs Rust 1.90

- The workspace and the desktop app now declare `rust-version = "1.90"`.
  Homebrew installs use prebuilt binaries and are not affected.

## Agent guides in the repository

- `CLAUDE.md`, `AGENTS.md`, `apps/desktop/CLAUDE.md` and the contributor skills
  under `.claude/skills/` and `.agents/skills/` (cut-release, rpc-change,
  store-migration) now ship in the repository for agents working on
  git-strata itself. The installed `git-strata` skill is unchanged.

passed in the full run and is unchanged in this release.
