# git-strata 0.3.0 — in-app updates and a bundled daemon

GIT STRATA shows the app and daemon versions in the status bar. Once the
daemon runs from the app bundle, you can install stable updates from the app.
The app, daemon and command-line tools update together.

## No store migration

The store schema stays at v7 and no migration runs on the first 0.3.0 daemon
start. 0.2.3 and 0.3.0 open each other's stores, so there is no backup to make
for the schema. `DOWNGRADE_FLOOR` remains 0.3.0 (set when the in-app upgrade
contracts landed): do not treat a build older than 0.3.0 as able to read every
persisted format this line writes. No config edits are required for the schema.

## Move an existing desktop installation

Follow these steps on each Mac that runs the formula's daemon with the desktop
app. Keep agents idle until the command-line tool is back on PATH.

1. Mark the formula as installed on request before upgrading the cask. This
   keeps Homebrew from autoremoving the formula when the cask drops the
   dependency. Use the named cask upgrade below because an unqualified
   `brew upgrade` can skip self-updating casks. Each command must succeed
   before the next runs.

   ```sh
   brew update &&
     brew tab --installed-on-request dickwu/tap/git-strata &&
     brew upgrade dickwu/tap/git-strata &&
     brew upgrade --cask dickwu/tap/git-strata-desktop
   ```

   If `brew tab` reports that the formula is missing, run
   `brew install dickwu/tap/git-strata`, then run the named cask upgrade.
   Continue only after both succeed.

2. Before restarting, check which executable the LaunchAgent uses.

   ```sh
   launchctl print "gui/$(id -u)/com.gwd.git-stratad"
   ```

   Confirm that `program` is the formula's daemon. Use that exact path to
   check its version, substituting it for the first path below if it differs.

   ```sh
   /opt/homebrew/opt/git-strata/bin/git-stratad --version
   /usr/bin/plutil -extract CFBundleShortVersionString raw -o - \
     "/Applications/GIT STRATA.app/Contents/Info.plist"
   ```

   The formula daemon and app must report the same stable version, 0.3.0 or
   later. The app checks its bundled daemon during the move. If any check
   fails, stop before restarting. If the tap has published only one of the
   matching packages, wait for both, then repeat the upgrade and version checks.

3. With matching versions and daemon work idle, restart the formula-backed
   LaunchAgent.

   ```sh
   launchctl kickstart -k "gui/$(id -u)/com.gwd.git-stratad" &&
     git-strata daemon status
   ```

   Wait for `data.running` to be `true`. Continue once `data.version` matches
   the version verified above and `data.features` includes `daemon.drain`.

4. Open GIT STRATA and choose **Move the daemon into the app** in the
   **Daemon** panel. The move keeps your config, store and sessions. macOS
   may ask for access to a removable volume. If macOS blocks the first open,
   follow the [Open Anyway instructions](../../README.md#macos-troubleshooting-for-030-and-later).

5. After the app confirms that the bundled daemon is running, remove the
   unused formula. Leave the daemon running and keep
   `~/Library/LaunchAgents/com.gwd.git-stratad.plist`.

   ```sh
   brew uninstall dickwu/tap/git-strata
   ```

   Immediately choose **Install command-line tool** in GIT STRATA. Hooks and
   agents that call `git-strata` need the new link before they resume.

6. Verify the CLI version and daemon status. Update the agent skill from your
   terminal.

   ```sh
   git-strata --version
   git-strata daemon status
   npx skills update git-strata -g
   ```

Use the in-app updater for later releases. New writes can receive `Busy` with
reason `draining` while the app waits for existing work to finish. `Busy`
with reason `daemon_down` is expected during the restart. Agents should
report the interruption and let the app finish. Retry unrecorded checkpoints
after the daemon is running again.

## Fresh installs and CLI-only systems

For a fresh desktop installation, install the cask and choose **Set up daemon**
in the app. See [Set up daemon](../../README.md#set-up-daemon).

If you uninstall the 0.3.0 desktop cask, `--zap` keeps the app's Application
Support folder, including `update.json`, the rollback archive under `previous/`
and the saved LaunchAgent plist under `legacy/`.

The formula remains available for CLI-only and headless systems. Follow the
[formula installation instructions](../../README.md#cli-only-or-headless-installation)
to keep any existing plist and config.
