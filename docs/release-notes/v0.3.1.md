# git-strata 0.3.1 — first published 0.3.x; self-signed CI signing

0.3.1 is the first published 0.3.x release. Tag v0.3.0 (commit fbc6a76) exists
on origin but has no GitHub Release: the first Release run failed because the
self-signed codesign secrets were not set, and a rerun after they were uploaded
failed when `codesign` could not find the imported identity on the macos-15
runner (`The specified item could not be found in the keychain`). Do not
install or update from that tag. This release is the one the in-app updater
and the Homebrew tap should use.

## No store migration

The store schema stays at v7. `DOWNGRADE_FLOOR` remains 0.3.0. 0.2.3, the
unpublished 0.3.0 tag, and 0.3.1 open each other's stores. No config edits
are required for the schema.

## Self-signed Release builds can sign on macOS 15

Official self-signed (and Developer ID) Release and Desktop pack jobs import
the identity into a throwaway keychain. On macos-15, `codesign --keychain`
alone does not reliably find that identity. The importer now adds the
throwaway keychain to the user search list for the signing steps and restores
the original list afterwards, including when a later step fails
(`import-identity.sh --restore` in an `always()` cleanup, plus an EXIT trap
if import itself fails after changing the list). The default keychain is not
changed, and the login keychain is not written to.

Existing 0.2.x releases were signed ad hoc. 0.3.1 is the first official
self-signed build, so the designated requirement changes and macOS will ask
for permissions again (for example removable volumes). Later 0.3.x updates
that use the same identity should keep those grants.

## Dependencies

Third-party crate and bun dependencies are unchanged since 2026-11-18 (the
0.3.0 bump). This release only refreshes this repo's own package versions in
the two lock files.

## Moving from 0.2.3

If you still run a 0.2.3 desktop installation with the formula daemon, follow
the [0.3.0 move steps](v0.3.0.md#move-an-existing-desktop-installation), but
install and check 0.3.1 rather than the unpublished 0.3.0 tag. After that,
use the in-app updater for later releases.
