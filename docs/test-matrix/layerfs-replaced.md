# 测试矩阵：LayerFS 被替代的部分

来源：`layerfs/core/crates` 的 `layerfs-api`（117）、`layerfs-daemon`（166）、`layerfs-fuse`（8）、`layerfs-sandbox`（28）、`layerfs-bridge`（25），共 344 个 `#[test]`，一条一行，行序为骨架生成器的路径排序。

读法：状态为 `替代` 的行，理由里写明替代物——真实目录、直接跑命令、无需认证通道（unix socket + JSON lines）、git；目标模块填承载替代物的我方模块：替代物是 git 时填 `gitio`（strata 总经 gitio 访问 git），替代物是 OS、APFS 或直接跑的命令本身时填 `—`。`改写` 的行是仍要写的测试：`fs.*` 查询语义映射 `cli`，checkpoint 与 overlay 状态映射 `overlay`，合并与发布映射 `publish`。`不保留` 的行在理由里点名是哪一条实现细节。

状态分布：改写 72；替代 173；不保留 99。
