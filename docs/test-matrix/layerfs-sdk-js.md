# LayerFS JS SDK 测试矩阵（3e）

> 来源：`layerfs/sdk/js/test/*.mjs`（6 个脚本）、`layerfs/sdk/js/test/verify/*.mjs`（13 个文件，均已入库）与 `layerfs/sdk/js/native` 里的 8 个 Rust `#[test]`（SDK 原生绑定的单元测试，不属于 3a–3f 的任何 crate）。JS 部分没有骨架可生成，条数由下面的枚举规则决定。
> 枚举规则：`trace.mjs`、`packaging.mjs` 取命令行选择器的每个取值（脚本自称 "each case is one command"）；`binary_write.mjs`、`exec_output.mjs`、`init_refusals.mjs`、`reinit.mjs` 没有选择器，取脚本里每个带注释头的场景块，后缀沿用脚本自己的名字（变量名、`fake.outputs` 的键、`refusedThenFixed` 的首参）；`reinit.mjs` 只有一个带注释的块，其后的生命周期流程算第二个；`verify/` 每个文件一行，不拆文件内的阶段；`sdk/js/native` 的 Rust 测试每个 `#[test]` 一行（由 matrix-common 的 awk 骨架生成器产出），列在表尾。分项：binary_write 4、exec_output 8、init_refusals 6、packaging 2、reinit 2、trace 9、verify 13、native 8（`src/discovery.rs` 1、`tests/unit/admission.rs` 2、`tests/unit/reclaim.rs` 5），共 52。
